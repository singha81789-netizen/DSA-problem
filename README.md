# Find the Duplicate Number

This project contains a solution to find the duplicate number in an array using an optimized approach in C++.

## Features
- Efficient algorithm
- Optimized time complexity
- Beginner-friendly code

## Language Used
- C++

## Problem
Given an array containing n + 1 integers where each integer is between 1 and n, find the duplicate number.
